# Peeky Task — Official Website

Official promotional website and landing page for **Peeky Task**, the minimalist screen-edge daily task widget for Windows.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS & Lucide Icons
- **Language:** TypeScript

## Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm start
```
